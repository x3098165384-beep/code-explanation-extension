# 术语与架构决定

## 阅读规则

探索代码或提出设计前：

- 如果根目录 `GLOSSARY.md` 存在，阅读与当前工作有关的术语。
- 如果 `docs/adr/` 存在，阅读与当前工作有关的架构决定记录。
- 文件尚不存在时直接继续；等实际确认了需要记录的术语或架构决定，再通过 domain-modeling 创建，不预先建立空文件。

## 文件位置

本项目使用一份根目录术语表 `GLOSSARY.md`，架构决定记录放在 `docs/adr/`。

## 使用术语和决定

任务、设计、代码说明和测试名称使用术语表已经确认的名称。

需要的概念尚未记录时，先判断是否能使用现有名称；确需新增术语时，交由 domain-modeling 记录。

方案与已有架构决定冲突时，明确指出对应记录、冲突内容和需要重新考虑的原因，不直接覆盖原决定。
