## 各任务共同适用的要求

- 本次只拆分任务。后续需有实施授权再执行，不能因发布为 `ready-for-agent` 就启动 VS Code、改代码或转换文件。
- 后续真实验证只能使用独立后台 VS Code、独立配置、扩展目录和案例工程。不切换桌面，不激活或操作请求者窗口，不向当前桌面发送鼠标或键盘输入。
- 拖选复制需实际选择文字、执行普通复制并核对相应剪贴板内容；整块复制单独操作和核对。截图、页面节点文字、截图上的选择颜色或直接调用整块复制接口均不能代替普通拖选复制。
- 实际复制前先确认剪贴板隔离，不能为验证覆盖请求者当前剪贴板后再恢复并称为没有影响。不能隔离或不能实际执行时记录未验证，任务 01 不算通过。
- 优先保留代码旁阅读和文字复制，允许简化边框、圆角及留白；仍须明显区分代码区域与说明。不修改用户主题、全局设置或 VS Code 安装文件，不用侧栏或正文页替代有效步骤的行内显示。
- 继续保持既有代码对应、Git、未保存源码、双侧检查、取消和资源释放规则。不保存额外源码副本，不重算旧摘要来掩盖失效，不操作游戏业务脚本或 Unity。
- 各任务运行与改动有关的既有检查及必要的构建检查。新增自动检查仅覆盖已明确的后台操作需求或难以人工稳定制造的保存、跳转、替换及停止顺序；不为测试另建生产状态或转发接口。
- 未操作的验收框保持未勾选。每项完成后记录实际结果、环境与限制；失败和未验证不能记成通过。先前 0.1.3 的 49 项后台及 34 项已有检查不能直接算作本轮结果。
