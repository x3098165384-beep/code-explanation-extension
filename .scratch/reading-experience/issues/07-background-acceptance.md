# 07：正式安装包的完整后台验收

Status: ready-for-agent

执行情况：未开始。

## 要完成的行为

使用同一份正式安装包，在独立后台 VS Code 中完成从侧栏找讲解、恢复进度、按步骤阅读普通代码和真实 diff、选择复制、正文回看、保存更新到停止的完整流程，交付可核对的运行结果和截图。

Blocked by: 03（排版正文与失效步骤回看）、05（继续上次讲解与最近打开记录）、06（调整外部生成检查并一次性转换旧讲解）

## 验收要求

- [ ] 前置任务均有完成记录，特别是任务 01 的实际选择及复制通过证据，不能以历史图片代码框检查代替。测试所用构建与最终交付安装包一致，记录版本、提交、包摘要和 VS Code 版本。
- [ ] 对照父规格的全部 22 项操作逐项记录通过、失败或未验证，给出对应结果和截图位置；不把当前未覆盖的环境扩大为已经通过。
- [ ] 验证左侧图标、项目目录、子目录、同名讲解、目录设置更新、展开步骤与直接跳步；列表刷新不自动开始或切换阅读。
- [ ] 用真实普通实例的磁盘记录跨进程验证继续上次、最近列表、同项目恢复及多项目隔离；重启无自动阅读，主动打开后重新核对代码。
- [ ] 覆盖普通当前文件、固定 Git、未提交内容、删除行、新增行、双侧目标及同一 diff 内切换，含未保存源码；只有正确侧的一份当前正文，范围和比较始终正确。
- [ ] 在普通、窄 diff、深浅主题及排版正文页中实际拖选部分和跨行代码，执行普通复制并比较剪贴板结果；整块复制另行检查缩进、空行、中文、反斜杠、引号和长行，保存实际输入与结果。
- [ ] 检查代码和短翻译的明显区分，允许简化外观，不使用图片或仅侧栏替代行内文字。实际复制、截图和页面节点检查各自说明证明了什么，不互相冒充。
- [ ] 无效 JSON、重复字段、不支持版本、临时不可读、失效目标、重复候选和 HEAD 变化均有具体错误；旧有效内容与正文回看保持一致，修复后恢复，源码变化仍参与检查。
- [ ] 快速切步、保存、替换、关闭正文页及停止后无迟到显示或错误复制。停止清除正文和范围，侧栏记录及代码页保留，订阅与资源已解除。
- [ ] 转换后的实际案例可按原标识和引用阅读，原旧文件保留；新版本拒绝旧 Markdown，不存在插件导入入口，不声称跨格式旧进度已自动迁移。
- [ ] 后台进程使用独立配置、扩展和案例，仅控制本轮隔离实例；记录桌面及进程归属，没有当前桌面输入、激活或切换窗口，没有覆盖用户剪贴板。
- [ ] 前后对照隔离案例的源码、未保存内容及 Git 状态，未修改或保存业务源码、切分支、改暂存区；不读取原项目窗口中的未保存文档，只在隔离案例中测试未保存修改。
- [ ] 相关已有检查、类型检查、构建及最终打包通过。只替换被新规格废止的旧格式或图片断言，仍保留有效代码对应、异步顺序及清理验证。
- [ ] 交付本次逐项结果、隔离记录、选择与复制结果、具有代表性的实际截图、完整运行日志位置及安装包，不只给操作步骤或使用旧包截图。

## 验证方式与完成标准

请求者已明确要求后台自行验证，因此本任务执行已有真实 VS Code 验收流程并补上前置任务新增入口，不要求请求者重复完成这些已覆盖的手测。保存、切步及停止的特殊完成顺序由已有可控顺序检查补足，界面和复制仍以实际运行结果为准。

出现失败先保留结果并修复或明确未完成范围，再复验受影响项。任何未操作的选择或复制项目都不能记为通过；不能在运行环境无法隔离时改用请求者窗口继续测试。
