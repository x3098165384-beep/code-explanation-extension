# 04：侧栏列出项目讲解并跳转步骤

Status: ready-for-agent

执行情况：未开始。

## 要完成的行为

阅读者点击 VS Code 左侧插件图标，在讲解侧栏看到项目目录中的讲解和可展开步骤。点击标题恢复该文件已有的步骤记录，点击步骤直接跳转；文件列表更新不抢占当前阅读。

Blocked by: 02（用 JSON 打开并更新行内讲解）

## 验收要求

- [ ] 左侧活动栏有能表达代码讲解用途的图标，深浅主题可辨认；点击打开专门侧栏，不以状态栏常驻菜单替代。
- [ ] 默认读取各项目根目录的 `.code-explanations/` 及其子目录中的 JSON，不扫描整个项目。可按项目设置更换目录，改动后重读并解除旧目录订阅。
- [ ] 按项目列出讲解标题及必要路径，区分同名文件，不重复列出同一文件，不因标题相同合并讲解。
- [ ] 目录不存在时显示实际目录和空状态；不可读、JSON 无效、没有项目时说明具体对象和原因。无效文件不伪造标题、步骤或进度，也不妨碍其他讲解使用。
- [ ] 展开讲解列出顺序正确的步骤，但不创建行内讲解、不打开代码页、不改变当前阅读。点击讲解标题恢复该文件已有有效步骤，首次从第一步开始；点击步骤直接从该步开始。
- [ ] 点击标题或步骤通过同一阅读流程接受最新合法文件后再显示；失效或过期列表项不能按旧编号跳到其他步骤，打开失败不破坏现有阅读。
- [ ] 侧栏标明当前讲解、步骤及进度，和现有上下步导航一致；不另存活动状态。连续点击及停止后，迟到列表或打开结果不恢复旧显示。
- [ ] 新建、修改、删除及恢复文件会更新列表；其他讲解变化不开始阅读或抢走当前步骤，当前讲解变化沿用既有保存更新规则。
- [ ] 保留选择其他位置 JSON 文件的入口；多项目时明确其代码所属项目，不按讲解所在目录猜测。侧栏展开不自动创建目录或文件。
- [ ] 停止阅读后侧栏仍可使用，当前正文与突出显示已清除、代码页保留；更换项目或扩展停用时解除不再需要的目录订阅。
- [ ] 后台实际验证图标、空状态、同名讲解、展开及跨文件步骤、目录变更、多项目与手动打开，并确认真实代码和 diff 显示正确，记录截图及结果。

## 验证方式与边界

本任务完成项目列表及导航，可使用已有单文件进度记录验证标题恢复；跨进程的最近打开和继续入口由任务 05 完成。不等待排版正文任务，避免为并行工作人为增加依赖。

沿用后台实例验证，只有新增目录和点击交错无法由人工稳定复现时，扩充相关既有顺序检查。目录展示、读取结果和活动阅读按实际所有者分别管理，不缓存第二套源码或选择状态。
