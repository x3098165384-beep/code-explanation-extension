## 要完成的行为

阅读者点击 VS Code 左侧插件图标，在讲解侧栏看到项目目录中的讲解和可展开步骤。点击标题恢复该文件已有的步骤记录，点击步骤直接跳转；文件列表更新不抢占当前阅读。

Blocked by: 02（用 JSON 打开并更新行内讲解）

## 验收要求

- [x] 左侧活动栏有能表达代码讲解用途的图标，深浅主题可辨认；点击打开专门侧栏，不以状态栏常驻菜单替代。
- [x] 默认读取各项目根目录的 `.code-explanations/` 及其子目录中的 JSON，不扫描整个项目。可按项目设置更换目录，改动后重读并解除旧目录订阅。
- [x] 按项目列出讲解标题及必要路径，区分同名文件，不重复列出同一文件，不因标题相同合并讲解。
- [x] 目录不存在时显示实际目录和空状态；不可读、JSON 无效、没有项目时说明具体对象和原因。无效文件不伪造标题、步骤或进度，也不妨碍其他讲解使用。
- [x] 展开讲解列出顺序正确的步骤，但不创建行内讲解、不打开代码页、不改变当前阅读。点击讲解标题恢复该文件已有有效步骤，首次从第一步开始；点击步骤直接从该步开始。
- [x] 点击标题或步骤通过同一阅读流程接受最新合法文件后再显示；失效或过期列表项不能按旧编号跳到其他步骤，打开失败不破坏现有阅读。
- [x] 侧栏标明当前讲解、步骤及进度，和现有上下步导航一致；不另存活动状态。连续点击及停止后，迟到列表或打开结果不恢复旧显示。
- [x] 新建、修改、删除及恢复文件会更新列表；其他讲解变化不开始阅读或抢走当前步骤，当前讲解变化沿用既有保存更新规则。
- [x] 保留选择其他位置 JSON 文件的入口；多项目时明确其代码所属项目，不按讲解所在目录猜测。侧栏展开不自动创建目录或文件。
- [x] 停止阅读后侧栏仍可使用，当前正文与突出显示已清除、代码页保留；更换项目或扩展停用时解除不再需要的目录订阅。
- [x] 后台实际验证图标、空状态、同名讲解、展开及跨文件步骤、目录变更、多项目与手动打开，并确认真实代码和 diff 显示正确，记录截图及结果。

## Comments

使用原生活动栏图标及讲解树，项目设置 `codeExplanation.directory` 默认 `.code-explanations`。目录列表只保留标题、文件及步骤标识；当前阅读和进度仍由 Reader 管理。展开只查看列表，标题恢复步骤，步骤点击按项目及稳定标识重新打开最新文件。

目录读取拥有自己的取消和订阅，不使用 Reader 的取消来源。设置或项目变化会解除旧订阅；目录本身和子目录文件均受监听，目录名称中的方括号按普通字符处理。旧列表项在真正打开时检查讲解与步骤标识，失败保留当前阅读。

正文页沿用 Reader 接受的内容更新，停止时关闭。查看正文不再取消尚未完成的源码定位；已补充可控制读取先后顺序的检查，验证慢读取之后仍出现行内讲解。
