## 要完成的行为

阅读者点击“查看正文”后，看到排版后的完整讲解，直接定位当前步骤，并可选择、复制代码。即使代码不能对应或讲解正在使用上一次成功加载的内容，仍能明确阅读对应正文，而无需进入 JSON。

Blocked by: 02（用 JSON 打开并更新行内讲解）

## 验收要求

- [x] 从当前成功接受的讲解生成完整标题、简介与所有步骤的排版内容，默认按稳定步骤标识定位当前步骤，不按 JSON 行号猜测。
- [x] 正文显示正常 Markdown 标题、段落、列表和代码，不展示定位对象、JSON 转义串或原始结构；替换任务 02 阶段保留的临时正文入口。
- [x] 代码真实可拖选、普通复制和整块复制；实际选择及剪贴板内容经验证，不能只检查代码节点文字或截图。
- [x] 代码目标无法对应时清除错误行内显示及范围，说明具体原因，仍能回看对应步骤正文；其他有效步骤继续保持行内阅读能力。
- [x] 新 JSON 无效或暂时读不到时显示当前已接受内容，并明确标注“上一次成功加载的讲解”，不混入新文件的部分标题或步骤。
- [x] 修好并保存后正文与当前步骤更新；重排仍按步骤标识定位，删除步骤或更换讲解按阅读流程选择结果显示，不另存当前步骤。
- [x] 更新、替换、关闭正文页、停止的先后顺序不会错误显示或复制旧正文；停止后不再持有活动正文或执行迟到更新。
- [x] 不为回看另存磁盘 Markdown，不开放作者脚本、任意命令或代码插入；辅助正文页不替代有效步骤在普通代码或 diff 旁的显示。
- [x] 后台实际演示完整正文、失效步骤、旧内容标识、修复保存及关闭和停止，保留截图与复制结果，并运行相关已有检查及必要构建。
