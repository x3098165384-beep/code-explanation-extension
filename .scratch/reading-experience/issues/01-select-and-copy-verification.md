# 01：先验证行内文字选择与复制

Status: ready-for-agent

执行情况：未开始。

## 要完成的行为

在真实 VS Code 的普通代码和实际 diff 旁，以文字显示短代码块及下面的简短翻译，实际拖选其中的字符或几行并复制，同时验证整块复制。使用最小案例证明可以保留行内位置和复制能力，再决定正式显示方式；代码框边框、圆角和留白可以简化。

Blocked by: None

## 范围

先使用独立案例和为验证必需的最小显示代码，不在此任务实现 JSON 阅读、目录侧栏、最近记录或转换真实讲解。当前旧案例仅可作为验证输入，不据此保留新版本的 Markdown 阅读能力。正文页也用最小案例确认排版文字及复制能力，不在本任务完成正式完整正文流程。

## 验收要求

- [ ] 记录 VS Code、测试扩展或安装包的版本及实际显示方式，使用独立后台实例，不改动请求者窗口、主题、全局设置或 VS Code 安装文件。
- [ ] 普通步骤在实际目标代码旁显示真实代码文字，代码与下面的翻译明显分开；不是矢量图、图片、侧栏说明或独立代码编辑页替代。
- [ ] 实际拖选部分字符与跨行文字，执行普通复制并读取相应剪贴板结果，与所选代码比较；只在页面中用代码设置选中范围、读取节点文字或只调用整块复制接口不算此项通过。
- [ ] 分别实际操作整块复制，确认结果包含代码的缩进、空行与字符，不含围栏、按钮、语言标签、行号、说明或排版填充字符；只允许为比对统一 Windows 与 LF 换行，不删除空行或空格。
- [ ] 实际 diff 覆盖删除行、新增行、两侧目标及在这些步骤间跳转；正文位于正确侧，两侧突出范围正确，同一比较保持，复制结果正确且只保留一份当前正文。
- [ ] 案例包含中文、反斜杠、引号、Tab、空行和长行；在普通宽度及窄 diff、默认深浅主题中检查可读性、选择与复制。代码区域仍明显区别于翻译。
- [ ] 用最小排版正文案例实际选择及整块复制，确认同一方案或可兼容的正文显示方式可用，不把原始 JSON 当作正文阅读页。
- [ ] 切换步骤、更新正文、替换讲解及停止后，旧复制操作不再读取错误步骤或已释放的正文；复制未改写源码和未保存内容。
- [ ] 验证剪贴板与用户桌面的隔离，记录实际复制命令、预期与实得文字及比较结果。不覆盖请求者剪贴板，不只证明测试扩展能写入预设文字。
- [ ] 保存普通文件、diff、正文页及深浅主题的实际截图，附每项结果、运行日志和隔离记录。截图不能代替复制结果。
- [ ] 所有上述核心选择与复制场景均有真实通过记录，才允许开始任务 02。无法运行、无法隔离或未能实际复制时明确记录未验证及原因，不以样式简化授权代替复制通过。

## 验证方式与完成记录

请求者已明确要求自行后台验证，现有手测既费时也无法证明后台方案不干扰当前窗口；沿用已有独立桌面和测试实例驱动，仅增加本任务必要的实际选择、复制和取值验证。窗口输入仅限确认属于本轮的隔离实例，不使用当前桌面的系统输入。

完成记录应给出可以复用的显示方式及限制，明确哪些真实操作通过。后续在任务 02 接入正式阅读流程时复用结果，不保留两套生产阅读状态。
