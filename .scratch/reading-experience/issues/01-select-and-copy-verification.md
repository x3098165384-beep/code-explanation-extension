# 01：先验证行内文字选择与复制

Status: ready-for-agent

执行情况：已完成，2026-10-22。

## 要完成的行为

在真实 VS Code 的普通代码和实际 diff 旁，以文字显示短代码块及下面的简短翻译，实际拖选其中的字符或几行并复制，同时验证整块复制。使用最小案例证明可以保留行内位置和复制能力，再决定正式显示方式；代码框边框、圆角和留白可以简化。

Blocked by: None

## 范围

先使用独立案例和为验证必需的最小显示代码，不在此任务实现 JSON 阅读、目录侧栏、最近记录或转换真实讲解。当前旧案例仅可作为验证输入，不据此保留新版本的 Markdown 阅读能力。正文页也用最小案例确认排版文字及复制能力，不在本任务完成正式完整正文流程。

- [x] 普通步骤在实际目标代码旁显示真实代码文字，代码与下面的翻译明显分开；不是矢量图、图片、侧栏说明或独立代码编辑页替代。
- [x] 实际拖选部分字符与跨行文字，执行普通复制并读取相应剪贴板结果，与所选代码比较；只在页面中用代码设置选中范围、读取节点文字或只调用整块复制接口不算此项通过。
- [x] 分别实际操作整块复制，确认结果包含代码的缩进、空行与字符，不含围栏、按钮、语言标签、行号、说明或排版填充字符；只允许为比对统一 Windows 与 LF 换行，不删除空行或空格。

- [x] 保存普通文件、diff、正文页及深浅主题的实际截图，附每项结果、运行日志和隔离记录。截图不能代替复制结果。

### 已证实的显示与复制方式

- 使用原生评论的引用块底色及边线，内部为受控 `pre/code` 真实文字，可增加受支持的颜色 span。代码区域与下面说明明显分开，不使用图片，也不添加框线字符或填充空格。
- 普通围栏会把 Tab 展开为空格，已实际复制确认。直接在 HTML 片段中保留字面 Tab、换行也会经过 Markdown 预处理；最终方案先将这两种字符编码为 HTML 实体，由浏览器还原成真实 Tab 和换行，再实际拖选复制，原文得到保留。
- 整块复制通过仅允许一个复制命令的入口完成，命令参数对应当前正文的随机标识。切换、更新、替换和停止清除旧标识；旧入口不改剪贴板，正文内其他命令的真实点击不执行。
- 正文使用最小只读 Webview 显示案例；在本轮专属内层页面量取位置，通过真实页面鼠标事件拖选并发送 Ctrl+C。没有用页面脚本设置选区，也没有把读取到的节点文字直接写入剪贴板冒充复制。
