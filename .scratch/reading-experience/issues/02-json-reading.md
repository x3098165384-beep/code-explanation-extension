# 02：用 JSON 打开并更新行内讲解

Status: ready-for-agent

执行情况：实现完成，2026-10-22。正式 JSON 阅读阶段已通过 9 项真实后台检查及 16 次实际复制比较；完整规格的其他后台流程由任务 07 继续复验。实施起点为 `c227738dcb21cd5c60e581d556c9c6505cf4859e`。

## 要完成的行为

阅读者主动选择一个已保存的版本 2 JSON 讲解，即可按步骤在普通代码或实际 diff 旁阅读、拖选复制及整块复制。保存修改后自动更新，重排保持步骤，错误更新保留原有效内容，停止后清除显示。

Blocked by: 01（先验证行内文字选择与复制）

## 验收要求

- [x] 按 JSON 格式约定读取标题、简介、代码引用及有序步骤，正确还原 Markdown、引号、反斜杠和换行；支持 UTF-8 BOM、LF 与 CRLF。
- [x] 主动打开覆盖普通当前文件、固定 Git 文件、两个固定提交 diff、HEAD 与当前内容 diff；沿用真实代码检查、双侧目标与新增或删除文件空白一侧规则。
- [x] 正式显示采用任务 01 已证实的文字方式，普通代码及 diff 均可拖选和整块复制，保留必要高亮和明显代码区域；复制来自当前正文代码块，不从当前项目文件另取一段替代。
- [ ] 保留上一步、下一步、步骤选择、编号及停止。第一步不能后退，最后一步不自动停止；同一 diff 跳转不退回普通文件、不累积正文。
- [x] 只有结构完整合法后才接受讲解并替换现有阅读。取消或打开无效文件时保留原阅读；未知版本、重复属性、未知字段、重复步骤标识及非法引用给出具体原因。
- [x] 正常阅读不再解析旧 Markdown，尝试打开时明确说明需要由 agent 转换；不增加导入入口，不尝试凭扩展名或相似字段兼容旧格式。
- [ ] 当前 JSON 保存后自动更新；按讲解和步骤标识保持位置，删除当前步骤回第一步，讲解标识改变从第一步开始。讲解未保存编辑不替换阅读内容。
- [ ] 无效保存或文件暂时无法读取时保留上一次成功加载内容并明确提示；仍对照最新源码检查，修复保存后自动恢复。
- [ ] 源码未保存编辑、JavaScript 允许的水平格式变化、重复候选、缺失资源、HEAD 变化仍按既有规则处理；不借更换格式扩大容错或保存源码副本。
- [x] 失效步骤清除旧行内正文和突出显示，并能回看可读正文，不直接打开 JSON 代替阅读。此阶段可沿用可读 Markdown 文档回看；完整排版页面由任务 03 完成，临时入口届时替换。
- [x] 阅读流程管理唯一的当前讲解和步骤；快速打开、切步、连续保存与停止的迟到结果不能覆盖新选择。停止解除订阅、取消读取、释放显示，保留代码页和有效步骤记录。
- [x] 通过正式解析入口及真实后台实例演示 JSON 打开、更新、错误恢复、diff 复制及停止，运行相关已有检查、类型检查和构建，保留实际结果及截图。

## 验证方式与边界

本任务从手动选择 JSON 开始，不等待侧栏或外部 skill。使用测试案例，不提前转换真实游戏讲解。最近文件列表及侧栏由后续任务增加。

更新现有受格式及图片显示变化影响的检查和案例，不能保留旧断言造成虚假失败，也不能删除代码对应、Git、取消和顺序检查。仅对已有顺序检查未覆盖的 JSON 连续保存与打开交错增加必要场景，原因是人工无法稳定控制读取完成顺序。
