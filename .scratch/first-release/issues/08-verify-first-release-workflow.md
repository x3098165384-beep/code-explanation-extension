# 08：用外部 agent 生成讲解并验收首版完整阅读流程

**要完成的行为：** 用外部 agent 为一个真实的跨文件修改生成讲解，完整走通打开、混合阅读、源码变化检查、讲解自动更新、停止和恢复进度，修正各项功能一起使用时暴露的问题，并给出可重复执行的首版使用说明。

**Blocked by:** 06：agent 保存讲解后自动更新，并保留当前步骤；07：下次主动打开讲解时恢复阅读进度。

**Status:** ready-for-agent

**当前进展：** 功能与后台准备已完成，正式手动验收待确认。验收项在取得对应实际结果前保持未勾选。

依据：[首版规格](../spec.md)全部 26 项手动验收、必要自动化要求及[Markdown 文件约定](../explanation-format.md)。汇总既有任务的实际证据，补上完整流程中的交互缺口；不再新增模型调用、录制、源码副本或独立阅读面板。

- [ ] 外部 agent 根据真实工程生成一份新的有效 Markdown，包含跨文件普通步骤、固定提交 diff、最近提交与当前内容的 diff，以及单侧和双侧目标。全部提交、路径、行号和摘要来自实际内容，不照抄演示工程引用。
- [ ] 读者按真实启动方式打开该讲解，前后跳转和步骤列表均能使用；混合比较之间不会读错版本、重复创建正文或留下上一处突出显示。
- [ ] 同时使用已暂存、未暂存及编辑器未保存内容，确认未提交比较和定位一致；HEAD 变化只使相关未提交比较要求更新，不破坏固定版本比较。
- [ ] 在当前阅读期间插入无关行、修改目标、制造重复目标，再由外部 agent 修改并保存讲解，确认重新定位、单步失效、自动更新和当前步骤保留同时成立。
- [ ] 在原讲解文件无效或暂时不可读时，让当前代码也变化；确认旧内容不会错误挂到代码旁，仍可读当前已接受正文，修复保存后恢复正常入口。
- [ ] 自动更新期间切换讲解、停止并重新打开，确认进度对应正确标识，停止不会被迟到读取或文件恢复重新启动。
- [ ] 复用并按需补齐任务 06 的可控读取检查，覆盖连续保存、快速切换、替换讲解和停止的交织顺序。不得只靠多次手动点击或延时等待证明这些情况没有问题，也不建立与实际流程无关的模拟框架。
- [ ] 汇总全部 26 项手动验收的实际结果和必要截图；此前证据仍有效的项目直接引用，存在新交互或修复影响的才重验。未运行、失败或不能满足的案例明确列出，不把文档检查当成运行通过。
- [ ] 通过项目实际建立的构建、类型检查和相关已有检查；修正完整流程中发现的问题，并只重跑受影响检查。单独的代码审查只有请求者明确要求时才另行安排。
- [ ] 使用说明写清怎样启动扩展、让外部 agent 生成讲解、手动打开、理解对应失败提示、自动更新、停止和恢复；说明不保存源码、不能恢复已丢失未提交代码，以及文本一致不代表业务含义已全部复核。
- [ ] 前后检查源码、HEAD、暂存区、未保存状态及停止后的显示，确认只读边界和清理责任在完整流程中仍成立。没有实现或未验证的功能不能列为首版已交付。
