# 02：打开 Markdown 并顺序阅读普通脚本讲解

**要完成的行为：** 阅读者手动选择讲解文件后，可以在当前项目文件旁顺序阅读、跨文件跳转、查看步骤列表和进度，并能完整停止。该任务交付第一段可实际使用的阅读流程，不单独交付解析层或空的扩展框架。

**Blocked by:** 01：在 VS Code 中验证真实行内讲解和 diff 两侧显示。

**Status:** ready-for-agent

**当前进展：** 功能与后台准备已完成，正式手动验收待确认。验收项在取得对应实际结果前保持未勾选。

依据：[首版规格](../spec.md)的验收 1、2、17、19、21、23、25、26；文件语法及字段以[Markdown 文件约定](../explanation-format.md)为准。本任务先播放引用当前项目文件的普通脚本步骤，历史内容和 diff 的实际播放由后续任务补齐。

- [ ] 建立最少必要的扩展启动、构建及运行方式，并通过实际的“打开讲解”操作接通文件读取、结构检查、代码检查、行内显示和导航。
- [ ] 只有一个项目根目录时直接使用，多个时明确选择；没有项目时给出操作说明。不根据讲解文件所在位置猜测项目，不接受越出所选项目的代码路径。
- [ ] 按文件约定读取已保存的 Markdown，识别文件头、步骤备注、标题和正文，顺序来自步骤出现顺序；代码块或引用中的相同标记不被误读为步骤。
- [ ] 缺少必要字段、重复属性或步骤标识、未知版本或字段、非法范围及摘要等结构错误阻止整份新文件进入阅读；首次打开无效文件时不创建半份阅读状态。
- [ ] 当前文件由编辑器管理，包含未保存源码；按约定的换行、BOM、整文件与目标范围摘要进行基本检查，不偷偷保存源码。本任务至少在文件未变化且范围对应时正确显示，不能核对的步骤说明原因而不是猜测位置。
- [ ] 每次只显示当前一步，突出正确代码范围；上一步、下一步、步骤列表跳转和步骤计数可用，支持多个当前项目文件之间的顺序阅读。
- [ ] 切换后清除上一处正文和突出显示；第一步不能后退，最后一步不能前进，最后一步内容保持到用户停止。
- [ ] 无法读取或无法核对的普通步骤不挂在错误位置，能打开原 Markdown 对应正文；其他可播放步骤仍能继续。完整的变动后重新定位由后续任务补齐。
- [ ] 仅在另一份讲解结构检查通过后替换当前阅读；取消选择或选择无效文件时保留当前阅读。尚未接通的历史或 diff 步骤不得被误报为 Markdown 结构损坏。
- [ ] 停止或扩展停用后清理行内正文、突出显示和不再使用的读取；代码页保持打开，旧读取即使稍后完成也不重新显示。进度持久化在后续任务补齐。
- [ ] 正文代码块仅用于阅读，备注或正文不获得执行脚本、插入代码或改写源码的能力；不自动扫描讲解目录，不接入模型或录制功能。
